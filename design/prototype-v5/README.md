# Prototype v5 (reference only)

The approved design prototype from 17 Nov 2026: black and gold, Fraunces and Plus Jakarta Sans, the nota racik, the 3D hero bottle. It is one HTML file with its own CSS and JavaScript.

- **Reference, not code.** Nothing here is built, imported or linted, and Prettier skips this folder (`.prettierignore`), so the file stays exactly as it was approved.
- **No images.** The photos it points to (`../img/…`, `card-*.jpg`) were never part of the repo, so they show as broken. The layout, the copy and the interactions are what matter.
- **Out of date in places.** Since then:
  - every perfume became its own product, so there is no scent choice
  - eyebrow labels above headings are banned
  - the light and dark modes (Gading and Noir) were added

  DESIGN.md and PRODUCT.md win wherever they differ from this file.

Where to look: the product page is the `#v-pdp` view (HTML around line 529, CSS around line 252, script around line 696). The home page sections come before it.
